childhood-memory is a tiny program that writes one childhood memory, a single sentence, to a text file. The memory is about a kite lost in the oak behind the school in June — watched as it snagged, never once checked on again, and still flying as long as nobody looks. The text is 178 characters long, well under the 280-character cap.

## Run it

```sh
python3 main.py
```

It writes the memory to `/output/entry.txt` (and a copy to `entry.txt` beside the script on a local run). No network access needed; the same text, byte for byte, on every run.
